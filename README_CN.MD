## 项目说明

这是唐墨夏的个人在线简历项目，内容覆盖 Web 前端、Android、UniApp 多端小程序、后台管理系统、Node.js 与移动端设备项目经历。

项目包含两种页面：

- `yarn run dev` / `yarn run build`：基于 `@fe_korey/mvvm` 的动态简历页
- `yarn run dev:seo` / `yarn run build:seo`：面向 SEO 的静态简历页

## 项目启动

1. 安装依赖

```bash
yarn
```

2. 启动开发模式

```bash
yarn run dev
yarn run dev:seo
```

开发地址：`http://0.0.0.0:8080/`

3. 打包生产代码

```bash
yarn run build
yarn run build:seo
```

4. 检查代码

```bash
yarn run lint
```
